# LinkAI 智能 AI 客服

LinkAI 智能 AI 客服是一个 WordPress 客户管理与在线客服插件，目标是逐步补齐类似 tawk.to 的实时接待、在线访客、人工接管、快捷回复、触发器、知识库、工单和报表能力。

## 当前已完成能力

- 前台聊天窗口、访客 ID、会话 ID、本地存储、消息轮询和到访上报。
- AI 自动回复、人工接管、AI 暂停/恢复和人工主动回复。
- 后台实时工作台、在线访客、客户记录、快捷回复、CSV 导出。
- 工作时间、在线/离线文案、离线留言、邮件提醒、浏览器通知和声音提醒。
- 满意度反馈、基础工单状态、内部备注、负责人、优先级、标签和跟进时间。
- 触发器、知识库、基础报表、附件上传和 PWA manifest。
- GitHub 更新检测、更新缓存清理和权限诊断。

## 与 tawk.to 的差异

当前版本已经具备客服系统的核心雏形，但仍是 WordPress 插件形态，不是完整 SaaS：

- 移动端目前为 PWA/响应式方向，尚未提供原生 iOS/Android App。
- 触发器、知识库、报表和工单为基础版本，复杂自动化、团队排班和多渠道接入仍需继续增强。
- 语音、视频、屏幕共享、WhatsApp/Facebook/Instagram 等多渠道能力尚未实现。
